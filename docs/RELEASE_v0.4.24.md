# Forkline v0.4.24

## 新增：刷新本地仓库

- 顶部“抓取”左侧新增 **刷新仓库** 按钮。在外部编辑器或终端修改文件、创建提交或调整分支后，可以主动更新本地分支、提交历史和工作区状态。
- 刷新时保留提交草稿、搜索条件、已加载历史深度和有效的选中提交，并尽量保持阅读位置。
- 刷新期间显示“刷新中…”，避免重复点击；读取失败后保留已有数据并提示错误。
- 只读取本地状态，不执行抓取、拉取、推送或提交。对应工单：#16。

## 操作体验改进

- 优化侧栏、底部区域、工作区分栏和提交列表列宽的连续拖动，减少重复布局计算，松手后准确保存位置。
- 明确“全部文件”和“所选文件”的操作范围，所选操作显示准确数量。
- 普通提交与“修改上次提交”分别保留草稿，避免切换模式或迟到的读取结果覆盖输入。
- 区分实际工作分支、正在查看的分支和提交目标，减少在错误分支上下文中操作的困惑。
- 搜索明确显示已加载的历史范围，可继续搜索更早提交。
- 抓取、拉取、推送后保留历史阅读位置；创建或修改提交后定位到工作分支的新提交。
- 减少普通暂存、抓取和提交的重复确认，远端写入、历史改写及丢弃操作仍保留确认。

## 自动刷新说明

现有工作区自动刷新保持不变：前台通常每 5 秒检查未提交修改；后台暂停请求，恢复活动时立即检查。变更文件达到 800 个且状态持续不变时，间隔逐步延长至 30 秒。

“刷新仓库”仅在点击时执行，不增加后台轮询频率。自动检查仍有本地 Git 和磁盘开销，大仓库或慢磁盘上的实际消耗取决于仓库规模和设备性能。

## 下载与更新

| 类型 | 下载文件 | 使用方式 |
| --- | --- | --- |
| Windows x64 安装版 | `Forkline-Setup-0.4.24-windows-x64.exe` | 运行安装器更新，保留个人设置 |
| Windows x64 绿色版 | `Forkline-v0.4.24-windows-x64-portable.zip` | 解压后运行 `Forkline.exe`，个人设置位于同目录 `data` |
| Windows x64 Web 包 | `Forkline-v0.4.24-windows-x64-web.zip` | 解压后运行 `Forkline.cmd`，继续使用 Git 快进更新 |

三种包均需要系统安装 Git。GitHub 自动生成的 **Source code** 压缩包仅包含源码，不是上述运行包。每种运行包均附 SHA-256 校验文件。

## 安全提示

Windows 包尚未进行代码签名，安装或运行时可能出现“未知发布者”或 SmartScreen 提示。请确认下载来源为本项目 GitHub Release，并核对同页提供的 SHA-256 校验文件。
