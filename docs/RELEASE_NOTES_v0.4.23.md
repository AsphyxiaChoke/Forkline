## 本次更新

- **新增绿色版（免安装）**：下载便携 ZIP，解压后双击 `Forkline.exe` 即可启动。整个文件夹可移动，个人设置保存在同目录 `data`，包内不携带开发仓库和测试记录。
- **绿色版应用内更新**：设置中的“立即更新并重启”下载对应 ZIP，校验后替换程序文件并保留个人数据；新版本启动失败时尝试恢复旧程序。
- **布局调整更自由**：提交信息列可以独立拉宽，超出可见范围时横向滚动；工作区、暂存区和提交信息区之间可以拖动调整宽度，并记住布局。
- **文件夹右键操作**：工作区和暂存区支持按目录批量暂存、取消暂存、丢弃和储藏，菜单按所在区域显示可用动作，保留 Windows 文件列表式选择。
- **提交多选与分组查看**：Ctrl 点选增减、Shift 连选、Ctrl+Shift 追加范围；右侧按提交分组展开各自更改，同名文件仍对应各自历史版本。
- **桌面状态栏**：窗口底部显示当前仓库、分支、更改数量及正在执行的 Git 操作。
- **精简发布资源**：保留中文和英文运行资源并加强压缩。安装包体积有所下降，主 EXE 仍包含 Electron 内核，未将其缩成几十 MB。

## 下载选择

| 版本 | 下载文件 | 使用方式 |
| --- | --- | --- |
| 绿色版（免安装） | `Forkline-v0.4.23-windows-x64-portable.zip` | 解压后运行 `Forkline.exe` |
| Windows 安装版 | `Forkline-Setup-0.4.23-windows-x64.exe` | 安装后从桌面或开始菜单启动 |
| Web 版 | `Forkline-v0.4.23-windows-x64-web.zip` | 解压后运行 `Forkline.cmd`，使用浏览器界面 |

三种包均要求电脑已安装 Git，不需要另装 Node.js。每个主要下载文件均附有 `.sha256` 校验文件。GitHub 自动生成的 `Source code` 是源码，不是绿色运行包。

## 更新与兼容

- 从 v0.4.23 起，文件名中的 `portable` 指绿色桌面版。**v0.4.22 及以前的 `portable.zip` 仍是 Web 包**，原附件和标签不改名、不覆盖。
- 绿色版使用 ZIP 更新，移动软件时保留整个文件夹及 `data`；Web 版和源码克隆继续使用 Git 快进更新。
- Windows 安装版继续通过 `electron-updater` / NSIS 更新，按当前用户安装、允许选择目录，并默认创建桌面和开始菜单快捷方式。
- 桌面更新前先优雅停止 Forkline 后台服务及其 Git/SSH 子进程；不改变原有 Git 操作语义。
- 保留 MergeView 连线、行对齐、语法高亮、独立编辑器窗口及双栏/三栏实时滚动同步。
