# v0.4.23 Issue 改动

本轮范围为 #3、#10、#11、#12、#13、#14、#15，随 v0.4.23 提供。下方本机统一验证记录来自升版前沿用 0.4.22 版号的隔离审计包，正式附件必须由 v0.4.23 标签重新构建，不覆盖旧版 Release。

## 界面

- #3：侧栏、详情栏和底部高度的上限随剩余窗口空间变化。提交信息列最低 80px，可独立拉宽；其他列不被联动压缩，过宽时在历史区横向滚动。底部工作区、暂存区、提交编辑之间新增分隔条，可拖动或用左右方向键调整；布局保存并支持设置页重置。
- #12：右键文件夹选中当前列表中该目录的后代文件，已完整选中目录时保留当前作用域的多选。工作区提供暂存、丢弃、储藏；暂存区提供取消暂存、丢弃、储藏。批量操作使用打开菜单时的文件快照，并沿用已有 Git 预检与危险操作确认。保持 Windows 文件列表式选择，不增加可选框。
- #13：Electron 主窗口底部增加 26px 状态栏，显示仓库、当前分支、更改数及正在执行的 Git 操作，与任务栏形成边界；普通浏览器中不显示此栏。
- #15：Ctrl 点选增减提交，Shift 选中锚点至目标之间的已加载提交，Ctrl+Shift 追加范围。右侧按提交分组，展开时按需读取文件，同名文件仍归属各自提交，双击打开该 SHA 的历史对照。首批显示 80 个分组，继续显示按钮访问其余分组；切换仓库、分支、搜索条件或历史改写使目标失效时清理旧选择。普通点选恢复原有单提交详情和 Git 操作。

## 发布包与更新

#10 / #11 增加 Electron 绿色版（免安装的便携 ZIP）和 ZIP 更新：解压后双击 `Forkline.exe`，整个文件夹可移动，个人设置保存在同目录 `data/`。绿色版无开发 Git 记录，更新保留个人数据，不使用 Setup。原 Web 包改用 `-web.zip`，仍保留 Git 快进更新；旧附件不改名、不覆盖。构建、故障恢复及历史命名说明见 [PACKAGING.md](PACKAGING.md)。

#14 清理无关 Electron 语言资源并使用最大压缩，保持现有 Chromium 和编辑器能力。主 EXE 的体积由 Electron 内核决定，本轮不会宣称已将 200 多 MB 的 EXE 缩成小程序；实际构建大小及测试证据记录在 progress.md。

## 验收标准

所有改动完成后统一执行：布局与选择行为、文件夹批量操作、三种更新分流、ZIP 校验与拒绝越界、更新成功与失败回滚；运行完整自动回归和真实 Chromium / Electron 快速滚动回归；在临时目录检查三种包。保留 MergeView 连线、行对齐、语法高亮和实时双栏同步，不改标准安装或既有用户设置。测试结论以 progress.md 中本轮 Testing 为准。
